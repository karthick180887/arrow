4. Data Flow Summary

x (3×1)   →  W₁·x + b₁  →  z₁ (4×1)   →  ReLU  →  a₁ (4×1)

a₁ (4×1)   →  W₂·a₁ + b₂  →  z₂ (4×1)   →  ReLU  →  a₂ (4×1)

a₂ (4×1)   →  W₃·a₂ + b₃  →  z₃ (1×1)   →  σ (sigmoid)  →  ŷ ≈ 0.6195

5. Why This Matters for Deep Learning

  • Every layer is a linear transform + nonlinear squish. Without σ or ReLU, stacking layers collapses to one big linear map — no real "depth".
  • ReLU kills neurons whose pre-activation is negative (we saw H₁₂ & H₂₃ die). This creates sparse, efficient activations.
  • Shapes must align. If (4×3) · (3×1) doesn't match, the whole pass breaks — always shape-check first.
  • Sigmoid at the output turns a raw number into a probability — perfect for binary classification.
  • Forward pass = one prediction. To learn, we compare ŷ with the true y, compute loss, and then backpropagate the error → that's the next chapter.
